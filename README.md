# Pixel Bike 2D 🚵

Піксельний **симулятор гірського велосипеда** у вигляді збоку — у дусі мобільних MTB-ігор на кшталт
*Mountain Bike Xtreme*, але з акцентом на реалізм. Велосипед не їде сам: ти крутиш педалі, гальмуєш,
переносиш вагу, стрибаєш з трамплінів і дропів, крутиш сальто й приземляєшся на обидва колеса.
Під капотом — фізика в справжніх одиницях: маса райдера й байка, хід підвіски, зчеплення шин
з ґрунтом, каменем, снігом чи льодом, потужність ніг і передачі.

Гра написана на **React + Canvas** без жодного графічного чи звукового файлу: траса, дерева, велосипед
і райдер намальовані кодом піксель за пікселем, а звук (шурхіт шин, вітер, тріскачка втулки, музика)
синтезується через Web Audio. Світ піксельний, а інтерфейс поверх нього — сучасний і мінімалістичний.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юніт-тести: фізика, генератор трас, проходження ботом, збереження
npm run lint       # ESLint
npm run build      # продакшн-збірка в dist/
npm run preview    # перегляд зібраної версії
npm run calibrate  # бот проїжджає траси і пропонує «золотий/срібний» час
```

Збірка використовує `base: './'`, тож `dist/` можна викласти в будь-яку папку (GitHub Pages, itch.io, Netlify).
Workflow `.github/workflows/deploy.yml` проганяє лінт, тести, збірку і публікує гру на GitHub Pages з гілки `main`.

## Як грати

| Дія | Клавіатура | Телефон |
|---|---|---|
| Крутити педалі | `↑` / `W` | велика кнопка справа |
| Гальмо (обидва колеса) | `↓` / `S` | кнопка «⊖» справа |
| Нахил назад: вілі, у повітрі — бекфліп | `←` / `A` | кнопка «↺» зліва |
| Нахил уперед: стопі, у повітрі — фронтфліп | `→` / `D` | кнопка «↻» зліва |
| Банні-хоп | `Пробіл` | кругла кнопка над педалями |
| Повернутись на чекпоінт | `R` | пауза → «На чекпоінт» |
| Пауза | `Esc` / `P` | кнопка ❚❚ |

- **Мета** — доїхати до фінішу якнайшвидше. Зірки дають **за час**: фініш — ★, «срібний» час — ★★,
  «золотий» — ★★★. Цільовий час показано перед стартом і на екрані вибору траси.
- **Падіння.** Якщо голова чи тулуб райдера торкнулися землі, або ти «пробив» підвіску, приземлившись
  з висоти на рівне, — райдер злітає з байка (видно, як він котиться схилом, а велосипед кувиркається
  окремо). Через 1,7 с ти відроджуєшся на останньому чекпоінті; секундомір при цьому не зупиняється.
- **Чекпоінти** — прапорці кожні ~200 м (на смузі прогресу вгорі — помаранчеві крапки, пройдені — зелені).
- **Знаки.** Жовті ромби, як у байк-парках, попереджають про тейбл, дроп чи геп. **Дуга монет** над стрибком
  показує траєкторію на правильній швидкості, велика монета над нею — для тих, хто «попнув» з губи хопом.
- **Трюки:** бекфліп (1000 очок), фронтфліп (1200), подвійні — учетверо більше; політ довше секунди;
  вілі й стопі (за метри на одному колесі); «чисте приземлення» — обидва колеса паралельно схилу (×1,25).
  Кожні 250 очок — монета на фініші.
- **Фрірайд** (відкривається після проходження траси) — нескінченна траса, що генерується щоразу заново
  і поступово ускладнюється. Одне падіння — кінець заїзду; рекорд дистанції зберігається.
- **Гараж:** 7 велосипедів і 7 комплектів екіпірування, купуються за монети.

## Фізика

Масштаб світу — **16 px = 1 м**: колесо 29″ має ~12 px у діаметрі, райдер — ~28 px заввишки. Уся фізика
рахується в справжніх одиницях (кг, Н, Вт, м/с²) і лише переводиться в пікселі; гравітація — 9,81 м/с².
Крок симуляції — 1/240 с.

**Модель «рама + безмасові колеса на підвісці»** (`bikePhysics.js`), як у симуляторах авто:

- Рама з райдером — **тверде тіло**: маса (75 кг райдер + 10–24 кг байк), момент інерції, кут, кутова швидкість.
- Кожне колесо ковзає **вздовж осі підвіски**: вилка — під кутом рульової колони (63–69°), задній
  амортизатор — майже вертикально. Де саме стоїть колесо, визначає **«каст» кола** вздовж осі до поверхні —
  тому колесо обходить каміння й корені і чесно вдаряється в гострі краї уступів.
- **Пружина з прогресією** (повітряна камера жорсткішає в кінці ходу), налаштована на просідання 30%
  під вагою райдера, і **демпфер** зі слабшим відбоєм і «пробоєм» на швидкому стиску.
- **Пробій.** Коли хід вичерпано, колесо впирається в упор — це жорсткий контакт. Якщо сумарний удар
  одразу після польоту перевищує ~5 м/с — падіння «жорстке приземлення» (у даунхілу поріг вищий).
  У хардтейла задньої підвіски нема — удар гасять лише покришка й ноги райдера (~5 см).
- **Колеса обертаються.** Педалі крутять заднє колесо, гальма гальмують обертання, а **тертя шини**
  (імпульсна модель з межею μ·N) перетворює обертання на рух — тож колесо може буксувати, а заблоковане
  гальмом — ковзати (занос, пил, слід).
- **Педалі:** сила ніг до 290 Н, потужність ~650 Вт і передачі: вище «максимальної» швидкості
  крутити вже нічим (у дьорт-джампера одна передача — ~38 км/год). Реакція приводу задирає ніс —
  на крутому підйомі без нахилу вперед байк перекидається назад. Е-байк додає мотор до 25 км/год.
- **Гальма** (190/240 Н·м задній/передній) з «розумним» переднім: райдер відпускає переднє гальмо,
  коли заднє колесо розвантажується, — інакше кожне натискання закінчувалось би польотом через кермо.
  Але з нахилом уперед це вимкнено: стопі або перекид — як у житті.
- **Нахил.** На землі — перенесення ваги (момент ~430 Н·м: трохи більше, ніж треба, щоб відірвати переднє
  колесо — вілі треба балансувати). У повітрі — кутове прискорення до 17 рад/с², у легких байків більше.
  Без нахилу райдер «тримає» байк, і обертання поступово гасне.
- **Опір кочення** залежить від покриття (пісок і багно гальмують), **аеродинамічний опір** — від швидкості.
- **Покриття** (`terrain.js`): ґрунт μ 0,88, камінь 0,95, бетон 1,0, дерево 0,78 (мокре — 0,55),
  корені 0,62, гравій 0,62, пісок 0,55, багно 0,45, **сніг 0,42**, **лід 0,1**; дощ знижує зчеплення.
  Фетбайк має множники зчеплення на снігу й піску.

Реалістичні наслідки, які перевіряють тести: на рівному з педалями — до ~40 км/год, з 40 км/год гальмуєш
за ~12 м, на льоду гальмівний шлях утричі довший, з гори 15% котишся до 60 км/год, підйом 10% —
~21 км/год, дроп 0,8 м на рівне безпечний, а 6 м на рівне — пробій.

## Генератор трас

`levelGen.js` будує висотне поле з кроком 12,5 см: «стежка» (плавний спуск) → «фіча» → стежка…
Фічі: **ролери** (памп-трек), **тейбли**, **дропи** (дерев'яні помости, скелі, бетонні уступи),
**гепи** (над водою, каньйоном, провулком), **кам'яні сади**, **корені**, **колоди**, **містки** над ярами
зі струмками, **підйоми**, **крутяки** 30–60%, **сходи**, **бордюри**, **компресії**, **броди**, смуги
**багна/піску/снігу/льоду**.

Головне — **реалізм і чесність**:

- Генератор паралельно «прокочує» **точкову модель райдера** (гравітація, кочення, повітря, педалі,
  пригальмовування на технічних ділянках) і знає очікувану швидкість у кожній точці.
- **Стрибки проєктуються з балістики**: довжина столу тейбла і кут схилу приземлення підбираються так,
  щоб на розрахунковій швидкості приземлитися за «колінцем»; короткий стрибок — просто на стіл.
- **Геп** будується лише там, де його реально перелетіти, **розігнавшись педалями з місця від останнього
  чекпоінта**; якщо розгону мало — перед гепом з'являється крутіший заїзд.
- **Дропи** мають схил приземлення, розрахований на помірну швидкість: «перелетіти» його на зайвій
  швидкості — жорстко, як у житті.
- Хвилі рельєфу мають **обмежену кривизну**, тож на гребені з типовою швидкістю не «вистрілює» в повітря;
  ролери, корені й камінь підібрані так, щоб колесо їх перекочувало з розгону.
- Чекпоінти — лише на пологих ділянках, декор стоїть на землі, монети — над нею.

**Бот** (`bot.js`) їздить як обережний райдер: тримає швидкість за підказками генератора, перед краєм
дропа відкидається назад, у повітрі передбачає точку приземлення і вирівнює байк під схил
(«час до приземлення»), перед колодою робить банні-хоп. Він крутить демо на фоні меню, а в тестах
доводить, що **кожну трасу можна пройти без падінь на кожному велосипеді**, і **від кожного чекпоінта
можна доїхати до наступного з місця**. Цільовий час — 93% (★★★) і 115% (★★) часу бота
(`npm run calibrate`).

## Графіка і звук

- **Земля колонками:** для кожного стовпчика екрана текстура покриття малюється від лінії поверхні вниз,
  тож шари ґрунту, сніг, пісковик і бетон «йдуть» уздовж схилу. У кожної траси — свій ґрунт:
  лісовий з корінням і камінням, цегла під бетоном міста, смугастий червоний пісковик, скелі під снігом.
- **Дерев'яні конструкції** (стартовий поміст, кікери, дропи, містки) — дошки з проміжками на опорах
  з розкосами, під ними видно справжню землю або струмок. Броди — напівпрозора вода над дном, гепи —
  море чи кам'яне дно ущелини, колоди — зріз з річними кільцями.
- **Паралакс по двох осях:** траса спускається, тож камера рухається й по вертикалі, а гори, ліс і місто
  зсуваються з різною швидкістю. Туман між далекими шарами — повітряна перспектива.
- **Велосипед і райдер** (`bikeSprite.js`) малюються щокадру з фізичної моделі: колеса там, де їх
  поставила підвіска (видно роботу вилки й амортизатора), покришки з грунтозацепами, диски, касета,
  ланцюг, шатуни; райдер — скелет з тих самих точок, що й фізичні зіткнення, коліна й лікті — зворотною
  кінематикою; нахил переносить тіло над заднє чи переднє колесо, на малій швидкості райдер сідає.
  Об'ємне світло зліва згори і поворот точок до растеризації — пікселі чіткі навіть у сальто.
- **Ніч:** темрява з променем фари вздовж рами, ліхтарі на трасі, дощ.
- **Звук їзди:** шурхіт шин (тембр залежить від покриття — бетон, гравій, сніг, дошки), свист вітру
  на швидкості, вереск заносу, характерна **тріскачка втулки**, коли котишся без педалей, глухий удар
  підвіски на приземленні, дзвоник чекпоінта.

## Як додати трасу

1. Скопіюйте об'єкт у `src/game/locations.js`: `id`, назва, `difficulty`, `lengthM`, `seed`.
2. Налаштуйте генератор `gen`: покриття (`surface`), ухил (`grade`), розмір фіч (`size`), швидкість (`vCap`),
   ваги фіч (`features`) і з якої частини траси вони з'являються (`from`), матеріали дропів/кікерів/гепів.
3. Опишіть небо, паралакс-шари (`layers`) і `paintGround` (палітра ґрунту — в `groundTextures.js`),
   декор `props`, `weather`, `fog`, `darkness`, `music`.
4. `npm run calibrate -- <id>` — бот проїде трасу і запропонує `times` (золото/срібло).
5. `npm test` перевірить, що траса чесна: бот проходить її без падінь, геп перелітається, декор стоїть на землі.

## Налагодження

У режимі `npm run dev` поточний рушій доступний у консолі як `window.__pixelBike`:

```js
const w = __pixelBike.world;
w.bike.place(w.track, w.finishX - 16 * 50);   // перенестись за 50 м до фінішу
w.gen.journal;                                 // список фіч траси з параметрами
```

## Збереження

Прогрес зберігається в `localStorage` (ключ `pixel-bike-2d/save/v1`, формат версії 2): монети, куплені
велосипеди й екіпірування, найкращий час і зірки кожної траси, рекорди фрірайду, налаштування.
Сейви попередньої версії гри мігрують автоматично: монети, скіни й відкриті траси зберігаються
(зірки, що давались за серця, обнуляються — тепер вони за час).
