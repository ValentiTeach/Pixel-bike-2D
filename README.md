# Pixel Bike 2D 🚲

Піксельна 2D гра-сайт про катання на велосипеді, написана на **React + Canvas** без жодного
графічного чи звукового файлу: усі спрайти намальовані кодом, звук і музика синтезуються через Web Audio.

Велосипед їде сам, а гравець рухається **лише по горизонталі** (вліво-вправо) і об'їжджає перешкоди.
Шість локацій, кожна зі своєю дорогою, декором, перешкодами, погодою та музикою.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm test          # юніт-тести логіки (Vitest)
npm run lint      # ESLint
npm run build     # продакшн-збірка в dist/
npm run preview   # перегляд зібраної версії
```

Збірка використовує `base: './'`, тож `dist/` можна викласти в будь-яку папку (GitHub Pages, itch.io, Netlify).
Workflow `.github/workflows/deploy.yml` проганяє лінт, тести, збірку і публікує гру на GitHub Pages з гілки `main`
(увімкніть *Settings → Pages → Source: GitHub Actions*).

## Геймплей

| | |
|---|---|
| **Керування** | `←` `→` / `A` `D`; на телефоні — тримати ліву/праву половину екрана (працює і мишею) |
| **Пауза** | `Esc` / `P`, кнопка ❚❚, автоматично при згортанні вкладки |
| **Меню** | `↑` `↓` + `Enter`; на екрані локацій `←` `→` або свайп |
| **Життя** | 3 серця. Після удару 1,6 с невразливості (велосипед мерехтить), швидкість падає |
| **Зірки** | скільки сердець лишилось на фініші — стільки зірок (1–3) |
| **Прогрес** | проходження рівня відкриває наступну локацію і нескінченний режим на поточній |
| **Монети** | валюта гаража; ланцюжок монет завжди веде безпечним проходом |

**Бонуси:** монета, серце (+1 життя або +5 монет, якщо життя повні), щит (7 с, розбиває одну перешкоду).
**Небезпечні зони** не забирають життя: калюжа/багно/пісок сповільнюють, лід/олія — занос з інерцією.

### Локації

| # | Локація | Траса | Перешкоди | Рухомі | Зона | Погода |
|---|---|---|---|---|---|---|
| 1 | Місто | 700 м | конуси, люки, авто, бар'єри | пішоходи | калюжі | — |
| 2 | Ліс | 900 м | каміння, пеньки, колоди | олені | багно | листопад |
| 3 | Пустеля | 1100 м | кактуси, каміння, черепи | перекотиполе | пісок | піщаний вітер |
| 4 | Гори | 1300 м | сніговики, крига, каміння, колоди | сніжки | лід | снігопад |
| 5 | Пляж | 1500 м | піщані замки, парасолі, відерця | краби, м'ячі | калюжі | анімоване море |
| 6 | Нічне місто | 1800 м | бар'єри, ями, авто, конуси | коти | олія, калюжі | дощ + темрява з освітленням |

Швидкість і щільність перешкод плавно зростають до фінішу. У нескінченному режимі швидкість після
«довжини рівня» росте далі (до +25%), а рекорд дистанції зберігається окремо.

**Гараж:** 7 скінів велосипедиста (перефарбування палітри спрайта), купуються за монети.
Прогрес, монети, скіни та налаштування зберігаються в `localStorage`.

## Архітектура

```
src/
├── game/                     # уся гра — чистий JS, React про неї майже нічого не знає
│   ├── constants.js          # роздільна здатність 180×320, фізика, таймінги
│   ├── rng.js                # детермінований генератор (mulberry32) + хелпери
│   ├── spriteData.js         # піксельні спрайти рядками-матрицями ('.' = прозорий)
│   ├── proceduralSprites.js  # спрайти, намальовані кодом: авто, дерева, будинки, калюжі…
│   ├── sprites.js            # розбір/перевірка матриць, кеш canvas, віддзеркалення, тіні, нахил велосипеда
│   ├── entities.js           # типи об'єктів: хітбокси, поведінка (static/cross/sideways), ефекти
│   ├── locations.js          # 6 локацій: дані + функції малювання дороги
│   ├── ground.js             # хелпери для безшовної плитки дороги
│   ├── spawner.js            # генератор рядків перешкод, монет, бонусів і декору
│   ├── world.js              # логіка світу без DOM: рух, зіткнення, фази, частинки, HUD-дані
│   ├── weather.js            # дощ, сніг, листя, пісок
│   ├── renderer.js           # малювання шарами, сортування за глибиною, нічне освітлення
│   ├── font.js               # бітмап-шрифт 3×5 для «+1» в canvas
│   ├── input.js              # клавіатура + сенсорні зони
│   ├── audio.js              # 8-бітні ефекти й чіптюн-секвенсор на Web Audio
│   ├── engine.js             # цикл requestAnimationFrame, під-кроки симуляції, події → звук/React
│   ├── skins.js              # скіни гаража
│   └── storage.js            # збереження (чисті функції + localStorage)
├── components/               # React-екрани: меню, вибір локації, гра (HUD, пауза, результат), гараж…
├── hooks/                    # useSave, useFrameScale (масштаб «пікселя»), useMenuKeys
├── App.jsx                   # навігація між екранами, застосування результатів заїзду
└── styles.css                # піксельний UI; усі розміри кратні --u (розмір ігрового пікселя)
tests/                        # Vitest: спрайти, генератор рівнів, заїзд, збереження
```

### Ключові рішення

- **Фіксована внутрішня роздільна здатність 180×320.** Canvas масштабується CSS-ом з
  `image-rendering: pixelated`, а весь React-інтерфейс задається в одиницях `--u`, тож пікселі UI
  і гри однакові на будь-якому екрані.
- **Логіка відділена від рендеру.** `World` не торкається DOM — його можна симулювати в Node.
  Тести проганяють цілі рівні ботом на кожній локації.
- **Чесний генератор.** Кожен «рядок-стіна» має прохід, ширший за гравця, і центр проходу
  зсувається не далі, ніж гравець фізично доїде: `maxShift = maxSpeed × (відстань / швидкість) × 0.6`.
  Рухомі перешкоди йдуть окремими рядками з запасом часу на перетин усієї дороги; після льоду
  досяжність зменшується вдвічі. Тест перевіряє ці гарантії на сотнях рядків.
- **Стабільний крок симуляції.** Кадр розбивається на під-кроки ≤ 1/120 с — без «тунелювання»
  крізь перешкоди на повільних пристроях.
- **3/4 вигляд згори.** Об'єкти сортуються за нижнім краєм, тож велосипед правильно
  проїжджає «перед» і «за» об'єктами; тіні — силуети спрайтів.
- **Нічне освітлення** — окремий шар темряви в половинній роздільності з «вирізаними» плямами
  світла (фара з конусом, ліхтарі, фари машин) та адитивним кольоровим сяйвом неону.

## Як додати локацію

1. Скопіюйте об'єкт у `src/game/locations.js`, задайте `id`, назву, `lengthM`, `speed`, межі `road`.
2. Опишіть `paintGround(ctx, rng, H)` — малює плитку дороги висотою 320 px (див. хелпери в `ground.js`).
3. Виберіть `obstacles` і `hazards` з `ENTITY_TYPES` (або додайте нові типи в `entities.js` + спрайт у `spriteData.js`).
4. Додайте доріжки `decor` (зони узбіч, відступи, набір спрайтів) і, за бажанням, `weather`, `darkness`, `music`.
5. `npm test` перевірить, що спрайти існують, декор не стоїть на дорозі, а проходи досяжні.

## Налагодження

У режимі `npm run dev` поточний рушій доступний у консолі як `window.__pixelBike`:

```js
__pixelBike.world.hearts = 99;                                   // безсмертя
__pixelBike.world.distance = __pixelBike.world.lengthPx - 300;   // одразу до фінішу
```
