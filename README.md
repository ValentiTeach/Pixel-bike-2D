# Pixel Bike 2D 🚲

Піксельна 2D гра-сайт про катання на велосипеді **у вигляді збоку** (як класичні платформери):
дизерингове небо, паралакс-гори й місто, трава зверху і земля з камінням знизу.
Написана на **React + Canvas** без жодного графічного чи звукового файлу: усі спрайти намальовані кодом,
звук і музика синтезуються через Web Audio.

Велосипед сам їде вправо по горизонталі. Гравець **стрибає** через перешкоди та ями, заїжджає на уступи
і керує швидкістю (гальмо / розгін). Шість локацій, кожна зі своїм небом, рельєфом, перешкодами, погодою та музикою.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm test          # юніт-тести логіки (Vitest)
npm run lint      # ESLint
npm run build     # продакшн-збірка в dist/
npm run preview   # перегляд зібраної версії
```

Збірка використовує `base: './'`, тож `dist/` можна викласти в будь-яку папку (GitHub Pages, itch.io, Netlify).
Workflow `.github/workflows/deploy.yml` проганяє лінт, тести, збірку і публікує гру на GitHub Pages з гілки `main`
(увімкніть *Settings → Pages → Source: GitHub Actions*).

## Геймплей

| | |
|---|---|
| **Стрибок** | `Пробіл` / `↑` / `W` — довше тримаєш, вище стрибок; є «буфер» натискання і «час койота» біля краю |
| **Швидкість** | `→` / `D` — розгін (×1.35), `←` / `A` — гальмо (×0.4) |
| **Телефон** | гра горизонтальна: зліва кнопки «гальмо» і «розгін», уся права частина — «стрибок» |
| **Пауза** | `Esc` / `P`, кнопка ❚❚, автоматично при згортанні вкладки |
| **Меню** | `↑` `↓` + `Enter`; на екрані локацій `←` `→` або свайп |
| **Життя** | 3 серця. Удар об перешкоду або падіння в яму — мінус серце (після ями повертаєшся трохи назад) |
| **Уступи** | стіна вищої платформи зупиняє велосипед — стрибай заздалегідь |
| **Птахи** | летять на висоті стрибка, вище голови — під ними треба проїхати, а не стрибати |
| **Зірки** | скільки сердець лишилось на фініші — стільки зірок (1–3) |
| **Прогрес** | проходження рівня відкриває наступну локацію і нескінченний режим на поточній |
| **Монети** | валюта гаража; дуга з монет показує, де і як високо стрибати |

**Бонуси:** монета, серце (+1 життя або +5 монет, якщо життя повні), щит (7 с, розбиває одну перешкоду).
**Небезпечні смуги** не забирають життя: калюжа/багно/пісок сповільнюють, на льоду/олії гальма не працюють.

### Локації

| # | Локація | Траса | Перешкоди | Назустріч | Птахи | Смуги | Атмосфера |
|---|---|---|---|---|---|---|---|
| 1 | Місто | 700 м | конуси, бар'єри, гідранти, авто | пішоходи | голуби | калюжі | денне місто, хмари |
| 2 | Ліс | 900 м | каміння, пеньки, колоди | олені | ворони | багно | гори, пагорби, листопад |
| 3 | Пустеля | 1100 м | кактуси, каміння, черепи | перекотиполе | орли | пісок | захід сонця, плато, піщаний вітер |
| 4 | Гори | 1300 м | сніговики, крига, каміння, колоди | сніжки | сови | лід | снігові вершини, снігопад |
| 5 | Пляж | 1500 м | піщані замки, парасолі, відерця | краби, м'ячі | чайки | калюжі | море з відблисками, пальми |
| 6 | Нічне місто | 1800 м | бар'єри, конуси, авто | коти | кажани | олія, калюжі | темрява, фара, ліхтарі, неон, дощ |

Швидкість і складність плавно зростають до фінішу. У нескінченному режимі швидкість після
«довжини рівня» росте далі (до +25%), а рекорд дистанції зберігається окремо.

**Гараж:** 7 скінів велосипедиста (перефарбування палітри), купуються за монети.
Прогрес, монети, скіни та налаштування зберігаються в `localStorage`.

## Архітектура

```
src/
├── game/                     # уся гра — чистий JS, React про неї майже нічого не знає
│   ├── constants.js          # роздільна здатність 320×180, фізика стрибка, таймінги
│   ├── rng.js                # детермінований генератор (mulberry32) + хелпери
│   ├── spriteData.js         # піксельні спрайти рядками-матрицями ('.' = прозорий)
│   ├── proceduralSprites.js  # спрайти, намальовані кодом: авто, дерева, ліхтарі, калюжі…
│   ├── bikeSprite.js         # велосипедист збоку: 8 кадрів педалювання, ноги через зворотну кінематику
│   ├── sprites.js            # розбір/перевірка матриць, кеш canvas, віддзеркалення, тіні
│   ├── entities.js           # типи об'єктів: хітбокси, поведінка (static/walk/roll/fly), ефекти
│   ├── locations.js          # 6 локацій: дані + небо, паралакс-шари, текстура землі
│   ├── background.js         # дизерингове небо, гори, пагорби, місто, хмари, море, земля з камінням
│   ├── levelGen.js           # генератор рельєфу (земля, ями, уступи) і викликів (перешкоди, птахи…)
│   ├── world.js              # логіка світу без DOM: фізика, рельєф, зіткнення, фази, бот
│   ├── weather.js            # дощ, сніг, листя, пісок
│   ├── renderer.js           # малювання шарами, сортування за глибиною, нічне освітлення
│   ├── font.js               # бітмап-шрифт 3×5 для «+1» в canvas
│   ├── input.js              # клавіатура + сенсорні зони
│   ├── audio.js              # 8-бітні ефекти й чіптюн-секвенсор на Web Audio
│   ├── engine.js             # цикл requestAnimationFrame, під-кроки симуляції, події → звук/React
│   ├── skins.js              # скіни гаража
│   └── storage.js            # збереження (чисті функції + localStorage)
├── components/               # React-екрани: меню, вибір локації, гра (HUD, пауза, результат), гараж…
├── hooks/                    # useSave, useFrameScale (масштаб «пікселя»), useMenuKeys
├── App.jsx                   # навігація між екранами, застосування результатів заїзду
└── styles.css                # піксельний UI; усі розміри кратні --u (розмір ігрового пікселя)
tests/                        # Vitest: спрайти, генератор рівнів, заїзд, збереження
```

### Ключові рішення

- **Фіксована внутрішня роздільна здатність 320×180 (16:9).** Canvas масштабується CSS-ом з
  `image-rendering: pixelated`, а весь React-інтерфейс задається в одиницях `--u`, тож пікселі UI
  і гри однакові на будь-якому екрані.
- **Паралакс.** Небо статичне (з упорядкованим дизерингом Байєра), далі 2–4 безшовні шари
  з різною швидкістю (хмари 0.05, гори 0.1, пагорби/місто 0.25–0.4, дерева 0.5), а земля рухається 1:1.
- **Рельєф із відрізків.** Земля — це список відрізків `{x0, x1, top}` трьох висот; проміжки між ними — ями.
  Велосипед приземляється на найвищу поверхню під колесами, а стіна вищого уступу його зупиняє.
- **Чесний генератор.** Після кожного виклику — розгін по рівному, довжина якого залежить від швидкості.
  Ширина ям і перешкод обмежена дальністю стрибка на поточній швидкості (`canClear`, `timeAbove`),
  птахи летять вище голови, але нижче вершини стрибка. Тести проганяють бота по всіх локаціях —
  він проходить їх без жодного удару.
- **Приємний стрибок.** Змінна висота (відпустив раніше — нижче), буфер натискання 0.13 с
  і «час койота» 0.09 с після з'їзду з краю.
- **Логіка відділена від рендеру.** `World` не торкається DOM, тож симулюється в Node.
- **Стабільний крок симуляції.** Кадр розбивається на під-кроки ≤ 1/120 с.
- **Нічне освітлення** — шар темряви в половинній роздільності з «вирізаними» плямами світла
  (промінь фари вперед, ліхтарі, фари машин) та адитивним сяйвом неону.

## Як додати локацію

1. Скопіюйте об'єкт у `src/game/locations.js`, задайте `id`, назву, `lengthM`, `speed`.
2. Опишіть `paintSky`, масив `layers` (паралакс) і `paintGround` — хелпери є в `background.js`.
3. Виберіть `obstacles`, `movers`, `flyers`, `hazards` з `ENTITY_TYPES` (або додайте нові типи в `entities.js`).
4. Налаштуйте ваги викликів `gen` (перешкоди, ями, уступи, птахи…), декор `props`, `weather`, `darkness`, `music`.
5. `npm test` перевірить, що спрайти існують, декор стоїть на землі, а рівень прохідний.

## Налагодження

У режимі `npm run dev` поточний рушій доступний у консолі як `window.__pixelBike`:

```js
__pixelBike.world.hearts = 99;                                   // безсмертя
__pixelBike.world.player.x = __pixelBike.world.finishX - 100;    // одразу до фінішу
```
